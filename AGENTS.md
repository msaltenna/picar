# Repository Working Rules

## Change isolation

- Every fix or feature must be implemented on its own non-default Git branch or in a dedicated Git worktree.
- Before editing code, verify that the active branch is not `main`, `master`, or another default branch. If it is, create a focused branch or worktree first.
- Do not combine unrelated fixes or features on the same branch.
- Keep the default branch clean and use pull requests to merge completed work.
